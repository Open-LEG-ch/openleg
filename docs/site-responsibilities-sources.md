# Responsibility explanation sources

The complete-site preview of `/how-it-works` implements the six roles and three
relationship views in issue #812, coordinated with #604. The existing default
page stays available while the complete-site switch is off.

The six SVG illustrations were drawn in the template for this page. They use no
third-party artwork. HTML ordered lists carry the electricity, data and payment
explanations; the solid, dashed and double lines add redundant visual cues.
The drawings describe responsibilities and handoffs, not an actual grid topology.

The regulatory reference was retrieved on 6 November 2026:
[ElCom FAQ, document updated 16 June 2026, chapter 9](https://www.elcom.admin.ch/dam/en/sd-web/weRgj22ICsTE/FAQ%20ES2050%20ab%20Mantelerlass_Update%20vom%2010.02.2026.pdf).
In particular, 9.1 to 9.3 discuss participation/network conditions, 9.4 to 9.5 distinguish
network and metering charges, and 9.8 to 9.9 cover data and billing-relevant quantities.
The VNB's residual-supply role is qualified by basic supply. Operator/hosting
choice does not replace statutory network processes.

Product statements refer to the current import, draft calculation, human approval
and self-hosting paths. A billing draft is not a bank payment. The page promises
neither universal VNB integration, free hosted operation nor complete operational
portability through a single export. Portability remains tracked by #601.

This records source and implementation checks. It does not record human approval
of the final German positioning (#604), legal review or native-language review.
Those remain prerequisites for the complete public launch.
