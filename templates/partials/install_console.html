OpenLEG mit einem Befehl selbst betreiben.

Installieren Sie OpenLEG direkt, wenn Sie wissen, was Sie tun. Der Installer erstellt lokale Zugangsschlüssel und startet App, PostgreSQL und Redis mit Docker. Ihre Messdaten bleiben in Ihrer lokalen PostgreSQL-Datenbank.

Für macOS und Linux mit Docker Compose, curl und OpenSSL.

curl -fsSL https://openleg.ch/install.sh | bash

Laden Sie das Skript zuerst herunter, lesen Sie es und starten Sie es danach selbst.

curl -fsSL https://openleg.ch/install.sh -o install-openleg.sh
less install-openleg.sh
bash install-openleg.sh

Für einen festen Checkout, den Sie vor Installation und Updates selbst prüfen.

git clone https://github.com/Open-LEG-ch/openleg.git
cd openleg
./scripts/openleg install
