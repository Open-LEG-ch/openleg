Selbst betreiben

Ihre LEG, Ihre Infrastruktur, Ihre Daten.

OpenLEG läuft auf Ihrer eigenen Hardware. Docker und eine Zeile genügen für den Einstieg.

Schnellstart

curl -fsSL https://openleg.ch/install.sh | bash

Schnellstart

Der Installer richtet OpenLEG mit Docker in einer Zeile ein. Ein Raspberry Pi, Mini-PC oder NAS genügt für den Anfang.

curl -fsSL https://openleg.ch/install.sh | bash

Sie können das Installationsskript vor dem Ausführen öffnen und prüfen.

Fortgeschritten

Klonen Sie das Repository und verwalten Sie Konfiguration, Updates und Betrieb selbst, wenn Sie volle Kontrolle wünschen.

git clone https://github.com/Open-LEG-ch/openleg.git
cd openleg
cp .env.example .env
docker compose up -d

Die souveräne Wahl

Ihre LEG betreibt die Box, und Ihre Daten bleiben in der LEG. Dafür übernimmt Ihr Team Updates, Backups und die Verfügbarkeit. Wenn Sie keine Wartung übernehmen möchten, nutzen Sie die gehostete Plattform als Alternative ohne eigenen Betriebsaufwand.

Offen und nachvollziehbar

Prüfen Sie den Code, passen Sie Ihre Installation an und behalten Sie die Kontrolle über den Betrieb.
