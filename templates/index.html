Was ist eine LEG?

Eine Lokale Elektrizitätsgemeinschaft ist ein Zusammenschluss von Haushalten und Betrieben, die in derselben politischen Gemeinde an derselben Netzebene angeschlossen sind und gemeinsam Strom aus erneuerbaren Anlagen verbrauchen. Sie ist seit dem 1. Januar 2026 in der ganzen Schweiz möglich. Rechtsgrundlage: Art. 17d und 17e StromVG sowie Art. 19e bis 19h StromVV.

Open Source. Weil Energieinfrastruktur allen gehört.

OpenLEG ist freie Software. Der Code liegt offen, jede Gemeinde kann die Plattform selbst betreiben, und niemand kontrolliert Ihre Energiedaten.

  • Gesamter Code auf GitHub, AGPL-3.0 Lizenz
  • In einer Zeile selbst installieren, auf einem Raspberry Pi oder Mini-PC
  • Freie API für Schweizer Energiedaten (ElCom Tarife, Sonnendach, Energie Reporter)
  • Keine Anbieterbindung: jederzeit selbst hosten oder migrieren
  • Community-Beiträge willkommen
